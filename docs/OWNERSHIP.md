# Ownership and Review Hygiene

This repository does not currently have a CODEOWNERS file because the workspace does not expose the real GitHub team or user handles needed to make it effective.

Use this guide until real owners are configured:

- Backend changes should be reviewed by someone who owns the Spring Boot API and Flyway schema.
- Frontend changes should be reviewed by someone who owns the React routes, shared components, and design system.
- Docs and workflow changes should be reviewed with the same discipline as code changes when they affect runtime behavior or release process.
